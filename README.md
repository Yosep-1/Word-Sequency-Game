# Word Sequency Game 🧠🗓️

An interactive memory game designed to test and train visual recall. This application challenges players to memorize a randomly generated sequence of months and recreate it under a strict time limit. Pay close attention! Study the pattern and prove the sharpness of your memory.

## 🎮 Features
* **Time-Attack Gameplay:** Players have exactly **8 seconds** to recall and identify the correct months.
* **Dynamic Scoring:** Points are awarded based on accuracy. Keep track of your score as you play multiple rounds.
* **Visual Memorization:** The game displays a specific set of months (some are hidden randomly) on a scroll, challenging your short-term memory.
* **Charming Aesthetics:** Features a mix of clean cartoon graphics and retro pixel art elements.

## 🕹️ How to Play
1. **Memorize:** On the Start screen ("Word Sequency"), carefully study the specific months displayed on the central scroll.
2. **Start the Clock:** Click the **START** button to proceed to the main game screen. You will have exactly 8 seconds on the clock!
3. **Recreate:** On the "Month Set Memory Game" screen, check the boxes next to the months you remember seeing on the previous screen.
4. **Score:** See your score update at the bottom right based on your correct selections. Use "NEW GAME" to try again and improve your memory sharpness.
